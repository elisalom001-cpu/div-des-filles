# A Vintage Tea Affair — Interactive Event Invitation

An interactive, mobile-friendly event invitation built for the SOJAM Division des Filles. The experience turns a traditional invitation into a small web application with animation, event details, RSVP handling, location links, and calendar support.

## Highlights

- Animated envelope-style invitation experience
- Responsive design for mobile and desktop
- Live event countdown
- Event details and venue directions
- RSVP form workflow
- Add-to-calendar interaction
- Progressive Web App support through a web manifest and service worker

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Web App Manifest
- Service Worker
- Form-based RSVP integration

## Project structure

```text
.
├── index.html             # Main invitation experience
├── styles.css             # Responsive visual design
├── script.js              # Interactions, countdown, and event behavior
├── manifest.webmanifest   # PWA metadata
├── sw.js                  # Service worker
└── assets/                # Images and supporting assets
```

## Engineering focus

The project focuses on delivering a polished event experience without a frontend framework. It combines responsive UI work, browser APIs, lightweight progressive-web-app features, and practical form integration in a small deployable codebase.
